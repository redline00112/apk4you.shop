How downloads work

Four quick steps. It usually takes about a minute.

  1. Tap  Download  on the game you want
  2. Complete one simple offer
  3. Get your download link
  4. Install and enjoy

Why is there an offer?

Offers keep Apk4You free for everyone. They may ask you to try an app or game, answer a short survey, or sign up for a service. Read each one before you start and only complete ones you’re comfortable with.

Installation tips

  • Install only from the official store. Don’t enable “Unknown sources”: modified APK files are a common way malware spreads.
  • Some games download extra data the first time you open them, so keep Wi-Fi on and leave enough free storage.
  • If something goes wrong, clear the app’s cache, restart your phone, update the game and your system, or reinstall.
  • Availability, pricing and beta programs are set by the store, so a game may not appear in your country.

Beta programs

Some publishers run official betas. When one is open, you can join it from the game’s store page. Apk4You never hosts beta files.
